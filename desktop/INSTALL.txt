Chirpberry 0.2.0 — Electron release candidate

macOS 26+, Apple Silicon. This build is ad-hoc signed and has not been notarized by Apple. macOS may prevent it from opening. Do not disable Gatekeeper or remove quarantine protection to install it.

Drag Chirpberry to Applications. Keep your original native Chirpberry app available until live recording, Fn, and your documents have been checked in this replacement. Quit the original app before enabling global shortcuts in the Electron app to avoid conflicts.

This app uses a separate Chirpberry Desktop notebook folder. Use Import to copy existing notes. Your original files are preserved.

Add your own Valsea API key in Settings and review cloud processing before recording. Valsea has separate account and usage costs. Recording starts only from a capture button or an enabled shortcut. No audio files are saved by default. Close the notebook to stop capture and quit.

The Mac integration appears as Chirpberry Capture in privacy settings. Allow Microphone for dictation, Screen & System Audio Recording for computer audio, and Accessibility for Fn. These permissions require your action.

This candidate is for acceptance testing. Packaging and synthetic tests do not establish live provider or Windows/Linux recording support.
